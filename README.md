# 📰 Agencia San Gabriel — Gestión de distribución de diarios

Aplicación de escritorio para administrar distribución, devoluciones, liquidaciones, publicidad y pagos del repartidor.

**Desarrollo:** Agustín Mansilla Emanuel

---

## Descripción

Agencia San Gabriel centraliza el trabajo diario de una agencia de diarios en una única aplicación. La interfaz agrupa los módulos de distribución, liquidación de ejemplares, publicidad y gestión del reparto, con consultas e informes para la administración.

## Funcionalidades

- **Distribución:** registro diario de diarios entregados y devueltos, clientes y canillitas.
- **Pago Norte:** cálculo de liquidaciones, movimientos y devoluciones.
- **Publicidad:** administración de avisos, clientes y pagos.
- **Pago del repartidor:** jornadas trabajadas, adelantos, ausencias y liquidación.
- **Informes:** reportes y comprobantes para consultar e imprimir.
- **Configuración:** parámetros de operación y herramientas administrativas.
